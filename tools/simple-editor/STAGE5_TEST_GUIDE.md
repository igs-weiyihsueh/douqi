# Stage 5 群組物件生成功能 - 測試指引

## 🎯 **功能驗證清單**

### **✅ 測試步驟**：

#### **1. 基礎生成測試**：
1. **重新載入編輯器** (Ctrl+F5，確認v8.0-generation)
2. **放置主物件** (點擊空白處生成)
3. **選中主物件** → 屬性面板顯示
4. **新增群組** → 點擊「+ 新增群組」
5. **檢查生成按鈕** → 應該看到「🎯 生成物件」按鈕

#### **2. 生成功能測試**：
1. **點擊生成按鈕** → 執行群組物件生成
2. **檢查控制台** → 查看生成日誌
3. **檢查畫面** → 預覽消失，真實物件出現
4. **檢查狀態** → 群組顯示「✅ 群組名 (已生成)」

#### **3. 狀態管理測試**：
1. **檢查按鈕消失** → 生成按鈕應該隱藏
2. **檢查控制項** → 已生成群組的參數應該disabled
3. **測試重命名** → 已生成群組不能重命名
4. **測試刪除** → 已生成群組不能刪除

#### **4. 混合狀態測試**：
1. **再新增群組** → 新增另一個群組
2. **檢查預覽** → 新群組應該顯示預覽
3. **檢查按鈕** → 生成按鈕應該重新出現
4. **選擇性生成** → 只有新群組會被生成

### **🧪 預期結果**：

#### **生成前狀態**：
- 群組顯示：`👁️ 群組1 (預覽中)`
- 預覽物件：半透明，綠色中心點，範圍圓圈
- 控制項：所有參數可編輯
- 生成按鈕：顯示且可點擊

#### **生成後狀態**：
- 群組顯示：`✅ 群組1 (已生成)`
- 預覽物件：消失
- 真實物件：完全不透明，可選擇，在entities列表中
- 控制項：所有參數disabled（灰色）
- 生成按鈕：隱藏（如果所有群組都已生成）
- 時間戳記：「已於 14:30:25 生成」

#### **生成日誌範例**：
```
🎯 開始生成群組物件 - 共 1 個群組
創建群組物件: 木箱_群組1_1 於 (150.0, 100.0)
創建群組物件: 木箱_群組1_2 於 (200.0, 150.0) 
創建群組物件: 木箱_群組1_3 於 (100.0, 150.0)
✅ 群組 "群組1" 已生成 3 個物件
🎉 群組生成完成！共生成 1 個群組，3 個物件
```

### **🎮 互動測試**：

#### **邊界測試**：
1. **移動群組到邊界附近** → 測試邊界內縮60px
2. **設定大半徑** → 測試越界物件跳過
3. **檢查日誌** → 應該有越界警告

#### **陣型測試**：
1. **圓形陣型** → 物件應該圍繞中心點呈圓形分布
2. **直線陣型** → 物件應該在一條直線上，間距44px
3. **方形陣型** → 物件應該呈現方格狀排列

#### **多群組測試**：
1. **創建多個群組** → 不同位置、不同陣型
2. **選擇性生成** → 部分生成，部分保持預覽
3. **混合管理** → 已生成和預覽群組共存

### **🚨 常見問題排查**：

#### **生成按鈕沒出現**：
- 檢查是否選中了主物件
- 檢查是否有未生成的群組
- 刷新頁面確認版本v8.0-generation

#### **生成沒反應**：
- F12打開控制台查看錯誤
- 檢查是否有JavaScript錯誤
- 確認selectedEntity存在

#### **預覽沒消失**：
- 檢查clearClusterVisuals是否執行
- 檢查cluster.generated是否設為true
- 手動調用renderClusterVisuals測試

#### **物件位置錯誤**：
- 檢查calculateFormationPositions計算
- 確認座標系統一致性
- 檢查攝影機變換
