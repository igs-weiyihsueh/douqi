# P1二段變身Goku皮膚切換功能測試指南

## 🎯 功能概述

實現了P1二段變身時自動切換Goku皮膚的功能：
- **普通狀態**：顯示Goku_1.png (基礎孫悟空)
- **強化狀態**：顯示Goku_2.png (金色光環版孫悟空，二段變身)

## 🎮 測試步驟

### 1. 基本皮膚切換測試
1. 啟動遊戲 (npm run dev)
2. 進入GameScene
3. 按**F4**鍵激活皮膚模式
4. 確認看到Goku_1.png皮膚覆蓋在P1角色上

### 2. 二段變身皮膚測試
1. 在皮膚模式下(F4已按，皮膚可見)
2. 讓P1進入強化狀態：
   - **Fast模式**: 攻擊命中10次觸發強化
   - **Slow模式**: 能量滿10或按Z鍵手動觸發
3. 強化期間皮膚應自動切換為金色光環版Goku_2.png
4. 強化結束後皮膚自動切換回普通版Goku_1.png

### 3. 完整流程測試
1. F4激活 → 看到普通Goku皮膚
2. 觸發強化 → 皮膚自動變金色光環版
3. 強化結束 → 皮膚自動變回普通版
4. F4關閉 → 皮膚隱藏，回到原場景

## 🔍 技術細節

### 資源載入
- `character-goku-skin`: Goku_1.png (44KB)
- `character-goku-skin-2`: Goku_2.png (128KB, 金色光環)

### 切換邏輯
- 基於`character.isEmpowered(time)`檢測強化狀態
- 使用`setTexture()`動態切換材質
- 只在狀態改變時更新，避免每幀重設

### Console訊息
測試時可觀察Browser Console的訊息：
```
✨ 角色皮膚已切換：Goku_2 (強化金色光環)
✨ 角色皮膚已切換：Goku_1 (普通)
```

## ⚠️ 潛在問題排除

如果皮膚不切換：
1. 確認F4已激活皮膚模式
2. 確認P1確實處於強化狀態(金光環效果)
3. 檢查Console是否有資源載入錯誤
4. 確認兩個Goku_*.png檔案存在於/public/assets/
