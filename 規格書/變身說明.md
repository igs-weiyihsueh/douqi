# 變身說明

## 變身類型

### 進場變身
- **觸發條件**：角色在待機區時投幣
- **操作方式**：投幣後出現特殊鍵提示按鈕，按下特殊鍵
- **角色選擇**：隨機選定變身角色
- **變身演出**：角色在待機區完成變身，然後進場
- **結束條件**：Credit耗盡不續關

### 武器變身
- **觸發條件**：遊戲途中出現武器時
- **操作方式**：靠近武器會出現特殊鍵提示，按下特殊鍵變身
- **角色選擇**：變身角色根據武器種類決定
- **範例**：
  - 金箍棒 → 孫悟空
  - 青龍偃月刀 → 關羽
- **變身演出**：角色高舉武器，體發光變成另一名英雄
- **結束條件**：Credit耗盡不續關

### 二段變身
- **觸發條件**：打敗怪物或擊中BOSS時累積「鬥魂」
- **操作方式**：鬥魂累積滿時出現特殊鍵提示，按下特殊鍵變身
- **變身演出**：角色被特效纏繞，身體瞬間放大
- **變身效果**：
  - 角色變大，身上纏繞特效
  - 無敵不受控場效果影響
  - 近戰攻擊強化為更大範圍，距離更遠
  - 命中4次會施放絕技
- **結束條件**：10秒後自動解除

### 合體變身
- **觸發條件**：觸發合體攻擊後
- **變身對象**：參與的角色會變成一隻千手觀音（暫定）
- **操作限制**：屬於表演，玩家無法進行操控
- **變身演出**：每個角色變成光球，在空中結合，變出千手觀音
- **變身效果**：
  - 變身對象不會因參與人數而改變
  - 人數越多，角色會越大隻
  - 人數越多，特效也比較強
- **結束條件**：攻擊完後解除變身
