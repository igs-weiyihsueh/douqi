# 編輯器關卡選擇器使用指南

## 🔍 **關卡選擇器位置**

### **位置：左側面板 → "場景設定" 區塊**
- 📍 **確切位置**：編輯器左側面板，"場景設定" 標題下方
- 🎯 **外觀**：下拉選單，包含 8 個關卡選項
- 📝 **標籤**："關卡" (在選單左側)

```
左側面板結構：
├── 物件清單
├── 資源庫  
├── Prefab 預設
└── 場景設定 ← 關卡選擇器在這裡！
    ├── 關卡: [下拉選單] ← 這就是關卡選擇器
    ├── 檔名: level1_001 (唯讀)
    └── 提示文字
```

## 🖱️ **如何使用**

### **步驟1：找到關卡選擇器**
- 開啟編輯器
- 查看左側面板
- 找到 "場景設定" 區塊（通常在左側面板下方）
- 看到 "關卡" 標籤旁的下拉選單

### **步驟2：選擇關卡**
- 點擊關卡下拉選單
- 選擇目標關卡（1-8）
- 檔案名稱會自動更新

## 🌐 **訪問路徑重要提醒**

### **⚠️ 請使用建置後的版本**：
- ✅ **正確路徑**：`/tools/scene-editor/dist/editor.html`
- ❌ **錯誤路徑**：`/tools/scene-editor/editor.html` (這是源碼版本)

### **💡 如何確認您在正確版本**：
1. 打開編輯器後
2. 檢查左側面板是否有 "場景設定" 區塊
3. 確認 "場景設定" 下方有 "關卡" 下拉選單
4. 如果沒有，請使用 `dist/editor.html` 路徑

## 🚀 **自動命名規則**
- **格式**：`level{關卡ID}_{編號}.json`
- **範例**：
  - 關卡1：level1_001.json, level1_002.json
  - 關卡4：level4_001.json (BOSS戰)
  - 關卡8：level8_001.json

## 🔧 **如果仍然找不到**

### **可能原因**：
1. **訪問錯誤版本** → 使用 `dist/editor.html`
2. **瀏覽器快取** → 硬重新整理 (Ctrl+F5)
3. **建置未完成** → 確認 `npm run build` 已執行

### **解決步驟**：
1. 確認路徑：使用 `dist/editor.html`
2. 清除快取：Ctrl+F5 硬重新整理
3. 檢查左側面板完整顯示
4. 尋找 "場景設定" 區塊

**如果按照以上步驟仍無法找到，請告知具體看到的介面狀況！** 🔍
