# 🎯 關卡編輯器使用指南

> 鬥氣割草關卡邏輯設計工具，配置遊戲目標、敵人AI、事件觸發和關卡參數。

## 📋 功能概述

### 核心功能
- **關卡邏輯設計**：遊戲目標、勝利條件、時間限制
- **敵人配置**：敵人類型、巡邏路徑、AI 行為
- **道具系統**：收集品、強化道具、隱藏物品
- **事件觸發**：時間事件、條件事件、劇情觸發
- **遊戲平衡**：數值調整、難度曲線、獎勵機制
- **場景整合**：基於場景編輯器輸出進行關卡設計

### 輸出格式
- **關卡檔案**：`.json` 格式 (關卡配置)
- **場景檔案**：`.douqi.json` 格式 (遊戲場景)
- **存放位置**：`public/assets/data/levels/` 和 `public/scenes/`

## 🛠️ 基本操作

### 建立新關卡
1. **點擊「📁 開新檔」**
   - 清空當前編輯內容
   - 重置為預設關卡模板

2. **設定關卡基本資訊**
   ```
   關卡 ID：level_001
   關卡名稱：測試關卡
   難度等級：easy / normal / hard / expert
   時間限制：180 (秒)
   分數目標：1000
   ```

3. **選擇基礎場景**
   - 在「場景目標」輸入框填入場景名稱
   - 對應場景檔案：`public/scenes/{場景名}.douqi.json`
   - 確保場景檔案存在且可訪問

### 配置遊戲目標
1. **主要目標設定**
   ```json
   {
     "id": "main_objective",
     "type": "collect",
     "description": "收集10個能量球",
     "target": 10,
     "reward": 500
   }
   ```

2. **目標類型**
   - **collect**：收集指定數量物品
   - **defeat**：擊敗指定數量敵人
   - **survive**：生存指定時間
   - **reach**：到達指定位置
   - **score**：達到指定分數

3. **可選任務**
   - 設定額外的獎勵任務
   - 提供額外分數和道具獎勵
   - 增加關卡重玩價值

### 敵人配置系統
1. **添加敵人**
   ```json
   {
     "id": "enemy_001",
     "type": "basic_enemy",
     "name": "基礎敵人",
     "position": [0, 0, 0],
     "rotation": [0, 0, 0],
     "properties": {
       "health": 100,
       "attackPower": 20,
       "moveSpeed": 2.0,
       "aiType": "patrol"
     }
   }
   ```

2. **敵人 AI 類型**
   - **patrol**：固定路線巡邏
   - **chase**：追擊玩家
   - **guard**：定點守衛
   - **random**：隨機移動
   - **aggressive**：主動攻擊

3. **巡邏路徑設定**
   ```json
   "patrolPoints": [
     [3, 0, 3],
     [3, 0, -3],
     [-3, 0, -3],
     [-3, 0, 3]
   ]
   ```

## 🌟 進階功能

### 道具系統配置
1. **收集品設定**
   ```json
   {
     "id": "collectible_001",
     "type": "energy_orb",
     "position": [1, 1, 1],
     "properties": {
       "value": 50,
       "effectType": "energy",
       "autoRotate": true,
       "rotateSpeed": 90
     }
   }
   ```

2. **強化道具**
   ```json
   {
     "id": "powerup_001", 
     "type": "attack_boost",
     "properties": {
       "duration": 10.0,
       "multiplier": 1.5,
       "stackable": false
     }
   }
   ```

3. **道具類型**
   - **energy_orb**：能量球 (加分)
   - **health_pack**：生命包 (回血)
   - **attack_boost**：攻擊強化
   - **speed_boost**：移動加速
   - **shield**：護盾保護

### 事件觸發系統
1. **時間事件**
   ```json
   {
     "id": "wave_001",
     "type": "enemy_wave",
     "triggerTime": 30,
     "description": "第一波敵人來襲",
     "enemies": [
       {"type": "basic_enemy", "count": 3}
     ]
   }
   ```

2. **條件事件**
   ```json
   {
     "id": "boss_trigger",
     "type": "boss_spawn",
     "triggerCondition": {
       "type": "enemyCount",
       "operator": "<=",
       "value": 2
     }
   }
   ```

3. **事件類型**
   - **enemy_wave**：敵人波次
   - **item_spawn**：道具刷新
   - **environment_change**：環境變化
   - **dialog_trigger**：對話觸發
   - **bonus_event**：獎勵事件

### 環境配置
1. **背景音樂**
   ```json
   "config": {
     "backgroundMusic": "battle_theme_01.ogg",
     "musicVolume": 0.7,
     "loopMusic": true
   }
   ```

2. **環境音效**
   ```json
   "ambientSounds": [
     {"file": "wind.ogg", "volume": 0.3},
     {"file": "birds.ogg", "volume": 0.2}
   ]
   ```

3. **天氣效果**
   ```json
   "weatherEffects": {
     "type": "clear",
     "windStrength": 0.3,
     "particles": false
   }
   ```

## 💾 檔案操作

### 儲存工作檔案
1. **點擊「💾 存工作檔」**
   - 儲存到 `public/assets/data/levels/Level01.json`
   - 包含完整關卡配置和編輯器專用資料
   - 用於繼續編輯和修改

2. **工作檔案內容**
   - 關卡基本設定
   - 所有遊戲實體配置
   - 事件和觸發器
   - 編輯器元資料

### 匯出遊戲場景
1. **點擊「📤 匯出場景」**
   - 轉換為遊戲引擎可讀取的格式
   - 儲存到 `public/scenes/{場景名}.douqi.json`
   - 移除編輯器專用資料，優化檔案大小

2. **場景檔案內容**
   - 精簡的關卡資料
   - 遊戲實體位置和屬性
   - 事件觸發器
   - 環境設定

### 載入現有關卡
1. **從工作檔案載入**
   - 在編輯器中開啟既有的關卡配置
   - 繼續編輯和修改

2. **從遊戲場景反向載入**
   - 將遊戲場景檔案轉回編輯器格式
   - 適用於快速修改和調整

## ⚠️ 注意事項

### 檔案命名規範
```
關卡檔案：level_001.json, forest_stage.json
場景檔案：level_001.douqi.json, forest_stage.douqi.json
避免使用：中文、空格、特殊符號
```

### 數值平衡建議
- **敵人血量**：根據武器傷害設定合理血量
- **移動速度**：確保玩家能夠逃脫或追擊
- **道具獎勵**：與關卡難度成正比
- **時間限制**：給予玩家充足但有挑戰性的時間

### 效能考量
- **敵人數量**：單螢幕不超過 10 個
- **事件密度**：避免短時間內大量事件觸發
- **道具數量**：適度控制同時存在的道具數

## 🐛 常見問題

### Q: 敵人無法正確移動？
A: 檢查巡邏點座標，確保路徑在場景範圍內且沒有障礙物阻擋。

### Q: 事件沒有按時觸發？
A: 確認觸發時間設定正確，檢查事件 ID 是否唯一。

### Q: 道具收集沒有反應？
A: 驗證道具類型設定，確保碰撞範圍合適。

### Q: 關卡載入後遊戲崩潰？
A: 檢查 JSON 格式是否正確，確認所有必要欄位都已填寫。

### Q: 匯出的場景檔案過大？
A: 移除不必要的編輯器資料，優化敵人和道具配置。
