# 攻擊說明

## 攻擊方式說明
### 近戰攻擊
- 基礎的攻擊方式
- 角色會稍微向前移動
- 扇形範圍攻擊，可攻擊正前方的敵人

### 衝刺攻擊  
- 快速衝向目標敵人
- 適合快速接近遠處敵人
- 衝刺途中碰到敵人會停下進行攻擊

## 攻擊判定邏輯
- 系統自動判斷與最近敵人的距離
- **近距離**：使用近戰攻擊
- **中距離**：使用衝刺攻擊
- **無敵人**：朝面向方向衝刺移動

## Credit 消耗規則
- 攻擊打空 = 不扣 Credit
- 攻擊命中 = -1 Credit（不管命中幾隻，一次攻擊動作最多扣1）
- 衝刺命中 = -1 Credit（同上）
- 普攻/招式1/招式2/絕技/衝刺統一消耗1
- Credit 歸零時：角色原地喘息不動，無法操作，期間持續受到怪物攻擊
- 歸零後一定時間內未投幣：角色傳送回待機區，解除變身，BOT補上場

## 招式系統規則
- 每5下觸發一次招式（需命中才計數，普攻或衝刺命中皆可累積）
- 循環：命中×4 → 招式1 → 命中×4 → 招式2 → 命中×4 → 絕技 → 重置
- 招式累積沒有中斷時間（不會因停止攻擊而歸零）
