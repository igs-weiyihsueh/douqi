# 專案概覽

## 基本資訊

**專案名稱**：鬥氣割草 (Douqi Cutgrass)  
**專案類型**：實驗性 H5 割草遊戲  
**遊戲類型**：俯視2D像素、雙操作模式、無盡刷分  

## 技術棧

**核心框架**：
- **Phaser 3.80.1** - 遊戲引擎
- **TypeScript 5.4** - 開發語言  
- **Vite 5.2** - 建構工具

**開發環境**：
- **工作目錄**：`/mnt/d/3C/douqi`
- **分支策略**：deploy-refactor (主要開發分支)
- **部署方式**：GitHub Pages

## 團隊結構

**3C團隊配置**：
- **異靈** (協調者) - 專案協調、需求分析、品質把關
- **翼騎** (主開發) - 核心功能開發、技術架構
- **征騎** (副開發) - 功能實作、系統優化
- **銳騎** (代碼審查) - 代碼品質檢查、規範執行

## 協作流程

**4段式開發流程**：
```
異靈(需求分析) → 翼騎/征騎(並行開發) → 銳騎(代碼審查) → 異靈(整合回報)
```

## 專案特色

**雙操作模式**：
- **快速滑鼠模式** - 適合快節奏操作
- **慢速鍵盤模式** - 適合精確控制

**核心玩法**：
- 俯視角度割草戰鬥
- 無盡刷分系統
- 像素風格視覺
