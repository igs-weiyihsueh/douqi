## 🔍 技術細節

### 比例常數設定
```javascript
const PX_PER_UNIT = 50;          // 與EntitySpawner.ts一致
const GAME_ORIGIN_X = 400;       // 與LevelManager.ts一致  
const GAME_ORIGIN_Y = 300;       // 與LevelManager.ts一致
const GAME_DESIGN_WIDTH = 1280;  // 遊戲設計解析度
const GAME_DESIGN_HEIGHT = 720;  // 遊戲設計解析度
```

### 物件尺寸計算
- **障礙物**: 25px半徑 × 2 = 50px直徑
- **敵人**: 14px半徑 × 2 = 28px直徑

### 陣型間距邏輯
- **最小間距**: 44px (基於config.ts中的敵人分離半徑)
- **彈性調整**: 當群組範圍小時，使用範圍的百分比
- **確保不重疊**: 間距不會小於物件安全距離

## 🎮 遊戲實際數值參考 (來自config.ts)

### 物件半徑
- `player.radius: 16`
- `enemy.radius: 14` (一般敵人)
- `enemy.tank.radius: 22` (Tank敵人)
- `障礙物估算: 25px` (基於視覺比例)

### 範圍設定
- `attackReach: 44px`
- `enemySeparation.radiusPx: 44px`
- `slow.lockRadius: 140px`
- `AI.alertRadius: 300px`
- `AI.loseRadius: 560px`

## ✅ 驗證方法

### 啟動檢查
編輯器啟動時會在控制台顯示：
```
=== 比例設定驗證 ===
像素/單位比例: 50px/unit (與EntitySpawner.ts一致)
遊戲世界原點偏移: (400, 300) (與LevelManager.ts一致)
=== 物件尺寸設定 (直徑) ===
木箱/石頭 (障礙): 50px (25px半徑)
炸彈 (敵人): 28px (14px半徑)
=== 陣型間距設定 ===
最小間距: 44px (基於敵人分離半徑)
群組預設範圍: 60px (基於攻擊範圍44px + 安全間距)
```

### 視覺檢查
1. **物件大小**: 木箱和石頭應比炸彈明顯大
2. **陣型間距**: 直線和方形陣型中物件不會重疊
3. **群組範圍**: 範圍圈大小合理，符合預期的攻擊/影響範圍

## 🚀 使用建議

### 設計關卡時
- 使用60px群組範圍作為基準攻擊範圍
- 直線陣型適合用於路障或防線
- 方形陣型適合用於區域控制
- 圓形陣型適合用於環繞保護

### 測試驗證
- 在編輯器中設計的布局應該在實際遊戲中看起來完全相同
- 物件間距符合預期的遊戲平衡
- 視覺效果與實際遊戲體驗一致
