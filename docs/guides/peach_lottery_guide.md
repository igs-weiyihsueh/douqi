# 🍑 桃樹彩票 - 遊戲指南 (UI增強版)

## 🎯 遊戲概述

「桃樹彩票」是一個基於運氣和時間壓力的淘汰賽小遊戲。四名玩家分別在四個區域中摘桃子尋找彩票，有彩票的玩家晉級，沒有彩票的玩家淘汰。

**全新UI設計確保您能清楚看到遊戲的每個細節！**

## 🎨 視覺改進亮點

### ⏰ **醒目的時間顯示**
- **大型計時器**: 48px字體，紅色背景，無法忽視
- **緊急警告**: 剩餘3秒時閃爍提醒
- **顏色變化**: 時間越少顏色越紅，視覺壓迫感

### 🎯 **清晰的選擇指示**
- **黃色高亮**: 選中的桃子會變成亮黃色並放大
- **旋轉光圈**: 選中桃子周圍有旋轉的黃色光圈
- **狀態顯示**: 實時顯示"選中桃X"還是"選擇中..."

### 🌳 **顯眼的桃子設計**
- **鮮紅色桃子**: 改用鮮紅色，更容易辨識
- **80x80尺寸**: 比原來大33%，更好點選
- **白色邊框**: 每顆桃子都有白色邊框標示
- **脈動動畫**: 桃子輕微脈動，增加生動感

### 👤 **明確的玩家標示**
- **"👤 你在這裡！"**: 紅色標籤明確指示P1位置
- **玩家脈動**: P1角色有醒目的脈動效果
- **彩色區域**: 四個區域用不同顏色清楚分區

## 🌳 遊戲設置

### 桃樹配置
- **四個區域**: 左上(P1-紅)、右上(P2-綠)、左下(P3-藍)、右下(P4-黃)
- **每區域4顆桃子**: 2x2排列，共16顆桃子，全部帶白邊框
- **玩家分配**: P1玩家控制，P2-P4為BOT自動玩
- **區域脈動**: 每個區域都有輕微的脈動邊框效果

### 彩票機制
- 每輪在可用桃子中隨機分配彩票
- **彩票數量 = min(存活玩家數-1, 1)**
- 摘到有彩票的桃子 → 晉級 ✅
- 摘到沒彩票的桃子 → 淘汰 ❌

## 🎮 操作方式 (大幅改善)

### P1玩家控制
- **左右方向鍵**: 在你的區域(左上紅色)內循環選擇桃子
- **空格鍵**: 摘取當前選中的桃子
- **視覺反饋**: 
  - 選中桃子: 變黃色+放大+旋轉光圈
  - 狀態顯示: "你(P1) - ✓ 選中桃X"

### BOT行為
- 自動在分配的區域中隨機選擇桃子
- 在時間過半後有機率自動摘取
- 狀態顯示: "BOTX - ✓ 選中桃Y" 或 "選擇中..."

## ⏰ 時間機制 (全面強化)

### 每輪時限
- **選擇時間**: 10秒倒計時，超大紅色顯示
- **視覺警告**: 
  - 6-10秒: 紅色背景
  - 4-5秒: 橙紅色背景  
  - 1-3秒: 紅色背景+閃爍效果
- **超時懲罰**: 未選擇的玩家直接淘汰

### 回合流程
1. **顯示回合信息**: "第X輪 (剩餘X名玩家)"
2. **選擇階段**: 10秒內各玩家選擇桃子
3. **揭曉階段**: 大型動畫顯示彩票結果
4. **進入下輪**: "準備下一輪..."提示

## 🎆 摘取結果顯示 (全新設計)

### 中獎效果 🎫
- **綠色桃子**: 變成大綠桃子(100x100)
- **發光效果**: 綠色光暈向外擴散  
- **浮動文字**: "🎫 中獎!" 大字飄上
- **狀態更新**: "你(P1) - 🎫 晉級"

### 沒中效果 ❌
- **紅色桃子**: 變成大紅桃子(100x100)
- **震動效果**: 桃子左右震動5次
- **浮動文字**: "❌ 沒中" 大字飄上  
- **狀態更新**: "你(P1) - ❌ 淘汰"

## 🏆 勝負規則

### 淘汰賽制
| 輪數 | 存活玩家 | 彩票數量 | 淘汰人數 |
|------|----------|----------|----------|
| 第1輪 | 4名 | 3張 | 1名 |
| 第2輪 | 3名 | 2張 | 1名 |
| 第3輪 | 2名 | 1張 | 1名 |
| 第4輪 | 1名 | - | **獲勝者** |

### 獲勝條件
- **最後存活**: 撐到第4輪的唯一玩家
- **大獎獲得**: 顯示金色獲勝文字和慶祝效果

## 🎯 操作提示 (基於新UI)

### 對P1玩家
1. **找到你的位置**: 看左上角紅色區域，有"👤 你在這裡！"標示
2. **選擇桃子**: 用←→鍵選擇，選中的桃子會變黃色+旋轉光圈
3. **確認摘取**: 按空格鍵，會有大型動畫顯示結果
4. **注意時間**: 紅色大計時器，剩3秒會閃爍
5. **觀察狀態**: 看你區域上方的狀態文字

### 遊戲特色
- **視覺增強**: 所有重要信息都用大字體+醒目顏色
- **即時反饋**: 每個操作都有對應的動畫效果
- **時間壓力**: 倒計時和顏色變化增加緊張感

## 🔧 結束選項
