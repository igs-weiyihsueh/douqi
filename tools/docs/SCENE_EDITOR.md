# 🏗️ 場景編輯器使用指南

> 鬥氣割草 3D 場景設計工具，支援物件擺放、材質編輯、光照配置和特效設定。

## 📋 功能概述

### 核心功能
- **3D 場景編輯**：實時 3D 場景預覽和編輯
- **物件管理**：模型載入、位置調整、縮放旋轉
- **材質系統**：貼圖映射、UV 調整、材質參數
- **光照配置**：環境光、太陽光、點光源設定
- **特效編輯**：粒子系統、視覺效果配置
- **碰撞設定**：碰撞盒配置、物理屬性

### 輸出格式
- **場景檔案**：`.douqi.json` 格式
- **存放位置**：`public/scenes/` 目錄
- **命名規範**：`場景名稱.douqi.json`

## 🚀 啟動編輯器

### 建置和執行
```bash
cd tools/scene-editor
npm install
npm run build
```

### 開啟編輯器
建置完成後，在瀏覽器中開啟：
- **路徑**：`tools/scene-editor/dist/editor.html`
- **建議瀏覽器**：Chrome 90+、Firefox 88+、Safari 14+

```
🎯 鬥氣割草 場景編輯器 | 📁 載入 | 💾 儲存 | ➕ 新增物件 | 🗑️ 刪除 | 🎮 預覽
```

- **光照控制**：光源類型、強度、顏色配置
- **特效設定**：粒子系統、環境效果

## 🛠️ 基本操作

### 視角控制
- **滑鼠左鍵拖拽**：旋轉視角
- **滑鼠右鍵拖拽**：平移視圖
- **滑鼠滾輪**：縮放視圖
- **中鍵拖拽**：自由移動視角

### 物件操作
1. **載入模型**
   - 點擊「➕ 新增物件」
   - 從資源清單選擇 FBX 模型
   - 模型自動載入到場景中心

2. **選擇和移動**
   - 左鍵點擊物件進行選擇
   - 拖拽控制軸移動位置
   - 按住 Shift 限制移動方向

3. **旋轉和縮放**
   - 切換到旋轉模式 (R 鍵)
   - 切換到縮放模式 (S 鍵)
   - 數值輸入精確調整

### 材質編輯
1. **選擇材質槽**
   - 在屬性面板選擇材質索引 (0, 1, 2...)
   - 每個材質槽對應模型的不同部分

2. **設定貼圖**
   - 點擊貼圖選擇器
   - 從資源庫選擇 JPG/PNG 檔案
   - 調整 UV 平鋪和偏移值

3. **調整材質屬性**
   - **顏色**：基礎顏色調整
   - **金屬度**：材質反光特性
   - **粗糙度**：表面光滑程度
   - **發光**：自發光效果

## 🌟 進階功能

### 光照系統
1. **環境光設定**
   ```
   環境光顏色：#ffffff (白色)
   環境光強度：0.3 (30%)
   ```

2. **太陽光配置**
   ```
   太陽光顏色：#fff8dc (暖白)
   太陽光強度：1.0 (100%)
   太陽光方向：[100, 300, 150]
   ```

3. **添加點光源**
   - 點擊「新增光源」
   - 設定位置和顏色
   - 調整光照範圍和衰減

### 碰撞設定
1. **碰撞盒類型**
   - **Box**：方形碰撞盒
   - **Sphere**：球形碰撞盒
   - **Mesh**：網格精確碰撞
   - **None**：無碰撞

2. **物理屬性**
   - **Static**：靜態物件 (不受物理影響)
   - **Trigger**：觸發器 (可穿過但產生事件)
   - **Size Override**：自定義碰撞盒大小

### 特效系統
1. **粒子效果**
   - 選擇預設效果類型
   - 調整粒子數量和生命週期
   - 設定發射速率和範圍

2. **環境效果**
   - 霧效設定
   - 天空盒配置
   - 後處理效果

## 💾 檔案操作

### 儲存場景
1. **命名規範**
   ```
   檔案名稱：scene_01, level_forest, boss_arena
   避免使用：中文、空格、特殊符號
   ```

2. **儲存位置**
   - 自動儲存到 `public/scenes/`
   - 檔名格式：`場景名.douqi.json`
   - 可手動指定輸出目錄

### 載入場景
1. **開啟現有場景**
   - 點擊「📁 載入」
   - 從 `public/scenes/` 選擇檔案
   - 支援拖放載入

2. **匯入資源**
   - 支援 FBX、OBJ 模型格式
   - 支援 JPG、PNG 貼圖格式
   - 自動處理材質關聯

## 🎮 預覽和匯出

### 場景預覽
- **預覽模式**：點擊「🎮 預覽」進入遊戲視角
- **自由飛行**：WASD 移動，滑鼠控制視角
- **ESC 退出**：返回編輯模式

### 匯出選項
1. **遊戲場景檔**
   - 格式：`.douqi.json`
   - 包含：場景資料、物件配置、光照設定
   - 大小：通常 10-100KB

2. **可執行遊戲**
   - 一鍵打包成獨立執行檔
   - 包含：場景 + 遊戲引擎
   - 適用：展示和測試

## ⚠️ 注意事項

### 效能建議
- **模型複雜度**：建議單個模型不超過 10K 面數
- **貼圖解析度**：建議 1024x1024 或以下
- **物件數量**：單場景建議不超過 100 個物件
- **光源限制**：實時光源不超過 8 個

### 檔案管理
- **定期備份**：重要場景請多版本保存
- **命名規範**：使用英文和數字，避免特殊字符
- **資源整理**：未使用的貼圖和模型定期清理

### 相容性
- **瀏覽器要求**：支援 WebGL 2.0 和 ES2020
- **檔案格式**：優先使用 FBX 模型和 JPG 貼圖
- **版本控制**：場景檔案建議納入 Git 版本控制

## 🐛 常見問題

### Q: 模型載入後顯示為黑色？
A: 檢查材質貼圖路徑，確保貼圖檔案存在於正確位置。

### Q: 場景太暗無法看清物件？
A: 增加環境光強度或添加額外點光源照明。

### Q: 儲存後找不到場景檔案？
A: 檢查 `public/scenes/` 目錄，確認檔案權限設定正確。

### Q: 編輯器載入很慢？
A: 清理瀏覽器快取，或使用較新版本的瀏覽器。

### Q: 匯出的遊戲無法正常執行？
A: 檢查場景中是否有遺漏的資源檔案或路徑錯誤。

## 🎯 最佳實踐

1. **模組化設計**：將大場景拆分為多個可重複使用的部分
2. **標準化命名**：使用一致的物件和材質命名規範
3. **效能優化**：適當使用 LOD 和遮擋剔除技術
4. **版本管理**：重要節點及時提交版本記錄
5. **團隊協作**：建立場景設計規範和資源共享機制
