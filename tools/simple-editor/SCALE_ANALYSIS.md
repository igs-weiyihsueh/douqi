# 編輯器比例問題分析報告

## 🚨 發現的比例不一致問題

### 1. **座標系比例差異**
- **遊戲執行時（權威標準）**: `screenX = position[0] * 50 + 400`, `screenY = position[2] * 50 + 300`
  - 比例: **50 px/unit**
  - 偏移: **(+400, +300)**
  - Y軸: **+z向下，不翻轉**

- **H5編輯器 (simple-editor)**: 
  - 比例: **1 px/unit** (直接使用 position 數值)
  - 偏移: **(0, 0)**
  - Y軸: **標準電腦圖學 +Y向上**

- **結果**: 編輯器中的物件會比實際遊戲小50倍，且位置偏移不正確

### 2. **物件尺寸設定**

#### 當前 simple-editor 設定：
- 木箱 (wooden_box): 16px
- 炸彈 (bomb): 13px  
- 石頭 (stone): 16px

#### 遊戲實際設定（從分析得出）：
- 一般敵人/物件: 14px (在50x比例下)
- Tank敵人: 22px
- 道具: 8px
- 強化: 12px
- 障礙: 25px
- NPC: 18px

### 3. **陣型間距問題**

#### 當前設定：
- 圓形: `radius` 直接作為半徑
- 直線: `spacing = radius * 1.5`
- 方形: `squareSpacing = radius * 1.2`

#### 應該對應的遊戲數值：
- 敵人分離半徑: 44px (遊戲像素)
- 攻擊範圍: 44px
- 各種範圍圈: 140px, 300px, 560px等

### 4. **世界尺寸設定**

#### 當前設定：
- `GAME_WORLD_WIDTH = 1600`
- `GAME_WORLD_HEIGHT = 1200`
- `cameraZoom = 0.4` (讓整個場地可見)

#### 實際遊戲：
- 設計解析度: 1280×720
- 世界單位轉畫面像素: 50倍縮放

## 💡 修正建議

### 方案A: 統一使用遊戲比例 (50 px/unit)
1. 修改物件繪製，使用 50 倍縮放
2. 調整攝影機初始縮放至 0.4/50 = 0.008
3. 修改陣型間距計算

### 方案B: 統一使用編輯器比例 (1 px/unit)  
1. 修改遊戲執行時的座標轉換
2. 統一所有相關工具使用相同比例

### 方案C: 建立通用比例常數
1. 定義 `PX_PER_UNIT = 50`
2. 所有工具都使用此常數進行轉換

## 🎯 建議採用方案A
保持遊戲執行時邏輯不變，修改編輯器以匹配遊戲比例，確保「所見即所得」。
