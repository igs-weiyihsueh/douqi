# 2D 關卡編輯器

## 功能特色

### 已實現核心功能
- ✅ **Pixi.js 7.x 渲染引擎** - 高效能 2D 圖形渲染
- ✅ **場景檔案載入** - 支援 JSON 格式場景檔案作為底圖
- ✅ **實體放置系統** - 拖拉放置敵人、道具、可破壞物
- ✅ **屬性編輯** - 即時編輯實體屬性和位置
- ✅ **多類型支援** - 敵人、道具、觸發器完整支援
- ✅ **檔案管理** - 關卡載入、儲存、匯出功能

### 實體類型
1. **敵人系統**
   - 步兵 (patrol AI)
   - 弓兵 (guard AI) 
   - 法師 (chase AI)
   - 可配置血量、速度、攻擊力、AI行為

2. **道具系統**
   - 金幣 (基礎貨幣)
   - 寶石 (高價值貨幣)
   - 補血包 (生命恢復)
   - 強化道具 (臨時增益)

3. **觸發器系統**
   - 區域觸發 (進入特定區域)
   - 時間觸發 (經過指定時間)
   - 條件觸發 (滿足特定條件)

### 編輯器介面
- **側邊欄面板**：場景設定、實體選擇、事件管理
- **主畫布**：場景預覽和實體編輯區域
- **工具列**：檔案操作和編輯工具
- **屬性面板**：選中實體的詳細屬性編輯

### 檔案格式
- **輸入**：2D 場景 JSON 檔案 (與翼騎場景編輯器相容)
- **輸出**：關卡 JSON 檔案 (包含所有實體和觸發器)
- **匯出**：遊戲可讀取的關卡資料格式

## 技術架構

### 核心系統
- `LevelManager` - 關卡資料管理和序列化
- `SceneLoader` - 場景檔案載入和顯示
- `PlacementSystem` - 實體放置和編輯系統

### UI組件
- `EntityPalette` - 實體類型選擇面板
- `PropertyPanel` - 屬性編輯面板

### 檔案結構
```
level-editor-2d/
├── src/
│   ├── core/           # 核心系統
│   ├── entities/       # 實體定義 (預留)
│   ├── systems/        # 功能系統
│   └── ui/            # UI組件
├── public/data/        # 資料檔案
└── dist/              # 構建輸出
```

## 使用方式

1. **載入場景** - 點擊工具列「載入場景」選擇 2D 場景檔案
2. **選擇實體** - 在側邊欄選擇要放置的實體類型
3. **放置實體** - 在畫布上點擊放置實體
4. **編輯屬性** - 點擊實體後在屬性面板編輯
5. **儲存關卡** - 完成編輯後匯出關卡檔案

## 與翼騎協作

### 相容性
- 使用相同的 Pixi.js 7.x 版本
- 支援載入翼騎場景編輯器產生的場景檔案
- 保持一致的 UI 設計風格

### 協作流程
1. 翼騎建立 2D 場景並匯出 JSON 檔案
2. 關卡編輯器載入場景作為底圖
3. 在場景基礎上配置遊戲邏輯和實體
4. 匯出完整的關卡檔案供遊戲使用
